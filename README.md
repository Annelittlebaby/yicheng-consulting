# 翼乘咨询 V2

公开网址：https://annelittlebaby.github.io/yicheng-consulting/

14 屏手机企业宣传册。此部署版将样式、脚本与 SVG Logo 全部内联到 index.html，无构建、无外部依赖。

## 文件
- index.html：完整站点
- .nojekyll：静态托管标记
- README.md：说明

## 修改
在 index.html 中搜索 YICHENG_CONFIG，填写真实微信、电话、邮箱或预约表单地址。留空时显示待补充；案例均为场景示例，非真实客户成果。

## 部署
Settings → Pages → Deploy from a branch → main → /(root)。

## 分享
标题、描述和公开地址已配置。微信自定义分享卡片仍取决于微信能力；本项目不含 JS-SDK 签名服务。
